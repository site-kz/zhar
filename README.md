# ЖАР — версия без вложенных папок

В архиве файлы находятся сразу в корне. Папки images НЕТ.

Файлы, которые должны лежать рядом:
- index.html
- style.css
- script.js
- menu-a.png
- menu-b.png
- menu-c.png

Распакуйте архив, откройте папку в VS Code и запустите index.html. Сборка не требуется.
Для загрузки на GitHub выделите перечисленные шесть файлов внутри распакованной папки. Изображения не переименовывайте. Сам ZIP загружать вместо файлов сайта не нужно. Устаревшая папка images для этой версии не используется.

## Изменения
В дополнительных ингредиентах: экстра сыр +250 ₸, жареный лук +150 ₸, халапеньо +200 ₸. Добавка томатов удалена. Томаты остаются в стандартном составе основных блюд, их можно убрать. Лук и другие ингредиенты можно убрать там, где они входят в состав. Исключения, добавки, количество и сумма попадают в WhatsApp-сообщение.
Сохранённая корзина переносится автоматически: отменённая добавка томатов убирается, остальные выбранные добавки и позиции остаются.

## Настройки
В начале script.js — CONFIG, WhatsApp 77766632330 (+7 776 663 23 30).
RAW_MENU — ассортимент, цены, вес и состав; EXTRAS — доступные добавки.
Изображения — три сетки 3×3, по одной ячейке на позицию. Менять расположение файлов не нужно.
Название, цены, вес и состав демонстрационные. Фотографии сгенерированы для концепта, не являются съёмкой конкретного ресторана. Перед коммерческим запуском согласуйте меню и реальную подачу.
Корзина сохраняется в браузере. Заказ открывается в WhatsApp, где клиент самостоятельно отправляет сообщение. Доставка рассчитывается отдельно. Оплаты через сайт нет.
Google Fonts загружаются при наличии интернета; без них работают системные шрифты.
